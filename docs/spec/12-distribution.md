# 12 — Distribution & releases

One static binary per architecture; every channel repackages the same GitHub Release artifacts.

| Channel | How | Notes |
|---|---|---|
| GitHub Releases | `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl` tarballs + `SHA256SUMS` + build provenance attestation | source of truth |
| Installer | `curl -fsSL https://raw.githubusercontent.com/prabhask5/moi/main/install.sh \| sh` | detects arch, verifies checksum, installs to `/usr/local/bin/moi`; `--version X`; installs `restic` from the distro if missing (asks) |
| `.deb` / `.rpm` | `cargo-deb`, `cargo-generate-rpm`, attached to releases | installs `/usr/bin/moi`, the unit file (disabled until `moi init`), shell completions, man page; apt repo later |
| crates.io | package `cestmoi`, binary `moi`: `cargo install cestmoi` / `cargo binstall cestmoi` | |
| Homebrew | tap `prabhask5/homebrew-tap`, formula `moi` | brew refuses to run as root; `moi init` prints the `sudo` command to install the system service |
| AUR / Nix | later | |

## Versioning & release flow

- SemVer. `CHANGELOG.md` (Keep a Changelog). Breaking: config keys, Kuma message formats, state layout, CLI flags.
- Tag `vX.Y.Z` on `main` → `release.yml`: build matrix (cargo-zigbuild for musl), strip, package tar/deb/rpm, checksums, attestations, create the GitHub Release with the changelog section, publish to crates.io (`CARGO_REGISTRY_TOKEN`), update the Homebrew tap formula (`HOMEBREW_TAP_TOKEN`).
- `moi --version` prints version, git sha, build date, target.
- The state dir and `moi.db` carry a schema version; moi migrates them forward on start and refuses to run against a newer schema.

### Decisions (M10)

- **What ships next to the binary is generated and committed**: `packaging/moi.service` (the unit `moi init` would write for `/usr/bin/moi`), `packaging/completions/` (bash, zsh, fish) and `packaging/moi.1`. Tests fail when they are not what the code generates (`MOI_UPDATE_GOLDEN=1 cargo test --test packaging`). Committed rather than generated at release time because the aarch64 binary cannot run on the build machine.
- **`moi completions <bash|zsh|fish>`** prints a script; `moi man` (hidden) prints the page. The tarball carries both, the unit and the documentation.
- **Packages** are named `moi`; the unit goes to `/usr/lib/systemd/system/moi.service` and is not enabled. `moi init` enables a packaged unit instead of writing a second one into `/etc`; `moi uninstall` disables it and leaves the file to the package manager. Removing the package stops and disables the service first. No dependencies (the binary is static); `restic` is recommended.
- **The packages are not signed** (no signing key exists yet): `SHA256SUMS` and the build provenance attestation vouch for them. Fedora's rpm refuses unsigned packages by default, so the rpm is installed with `dnf install --nogpgcheck ./moi-*.rpm`. A signed apt/dnf repository is the "apt repo later" of the table.
- **Installer**: the checksum is compared by this script, not by `sha256sum -c` (whose exit status hides a file that is simply not listed): a release that does not list the tarball, or lists another sum, installs nothing. `--yes` installs restic without asking; otherwise it asks on a terminal and only notes it elsewhere. `MOI_RELEASE_URL` points it at a mirror (and at the test's own release).
- **`moi --version`**: `moi X.Y.Z (sha date target)`; the date is `SOURCE_DATE_EPOCH` when set.
- **Dry run**: a fork was not available, so the same thing is done in place — `release.yml` run by hand or by a pull request that touches packaging builds both targets, packages tar/deb/rpm, and the `verify` job installs them (installer against a local release and against the built artifacts; the `.deb` on Ubuntu 24.04, 26.04 and Debian 13; the `.rpm` on Fedora; the Homebrew formula parsed; `cargo package`). Publishing jobs (GitHub Release, crates.io, Homebrew tap, attestations) run for tags only, and a tag must equal the version in `Cargo.toml`.
- **Homebrew**: a Linux-only binary formula generated by `packaging/homebrew-formula.sh` from the release's `SHA256SUMS`; its caveat gives the two `sudo` commands, since brew does not run as root.
